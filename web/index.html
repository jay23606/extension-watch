Methodology

Every grade comes from published rules. No model, no hidden weights.

Each finding is worth points by how much it can reach. Findings that describe the same power (for example broad host access, content scripts on all sites and script injection) form a group, and a group counts once, at its highest value. The score is the sum of the groups, capped at 100. Optional permissions are listed with 0 points because the browser does not grant them at install. Grade bands run from 0 to 19 for A, 20 to 39 for B, 40 to 59 for C, 60 to 79 for D, and 80 or more for F.

Threshold mode leaves extensions that are not on the list installable and blocks only the listed extensions graded at or below the threshold. Default deny blocks every extension that is not on the list. Both modes keep every extension off the debugger permission and off the sensitive sites.

To apply the policy, open the Google Admin console, go to Chrome browser, then Custom Configurations under Chrome Enterprise Core. Paste the downloaded JSON as the ExtensionSettings policy value. On Windows, deploy the same JSON through the Chrome Group Policy templates. On macOS, add it to the com.google.Chrome configuration profile plist. On Linux, write it to a file under /etc/opt/chrome/policies/managed/.
